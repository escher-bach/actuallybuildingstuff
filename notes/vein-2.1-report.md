## 1. Radical/incidental methodology — PRIORITY

**Two lineages converge on the same object, with different vocabularies.**

| Lineage | Vocabulary | Source |
|---|---|---|
| Irvine & Kyllonen (2002) *Item Generation for Test Development* | **radicals** / **incidentals** | edited volume, LEAD (not fetched directly, definition corroborated by multiple secondary sources + Cambridge slide deck below) |
| Embretson **Cognitive Design System (CDS)** | item-stimulus features selected via a **cognitive model**; "construct representation" | Embretson 1998 *Psychometrika* "Generating items during testing: psychometric issues and models"; Embretson 2002 book chapter in Irvine & Kyllonen — VERIFIED via Cambridge slide deck (below), which uses "radicals" as a gloss for Embretson's cognitive-model-selected item-stimulus features, i.e. treats the two lineages as the same object |
| Gierl & Lai **AIG / "item model"** | **elements** (in stem/options/auxiliary info), no radical/incidental split named | Gierl & Lai 2013, NCME ITEMS Module 34, VERIFIED full text — see below |

**Operational definitions, as stated in sources:**
- Radicals: "item design features hypothesized to affect the item parameters" / "structural elements that significantly affect item parameters such as item difficulty" (search-snippet synthesis, corroborated by slide deck below — LEAD/VERIFIED mixed, see §8)
- Incidentals: "non-salient item design features (surface features) that do not affect the item parameters," "surface features which do not exert an influence on the item parameters and can be used interchangeably to generate psychometrically identical but superficially different items" (same status)
- Cambridge Psychometrics Centre slide deck (Aiden Loe, "Item Generation," psychometrics.cam.ac.uk/system/files/documents/AIG.pdf — **VERIFIED, fetched and read in full, 60 slides, no page numbers/citations beyond speaker attributions, "References Upon Request" only**) states verbatim on the "Item Features" slide: "**Radicals** – Features that influence item difficulty" / "**Incidentals** – Features that no [sic] do influence difficulty but changes the content of the question," with a worked example: *"John has 15 sweets. He shared 5 with Mary, and 2 with Paul. How many sweets does he have left?"* — 15/5/2 marked radical (red), John/Mary/Paul marked incidental (green). On the "CDS approach" slide: "Item construction process starts with a specification of item-stimulus features (**radicals**) that can be systematically varied," "Item stimulus features (radicals) are selected on the basis of a **cognitive model** that outlines the cognitive processes involved in solving a particular item type" — **this slide explicitly relabels Embretson's CDS item-stimulus features as "radicals,"** confirming the two lineages are treated as one object in at least this secondary presentation.

**The empirical procedure for telling radical from incidental — the priority ask — found concretely in one place: PMC7298330** (Hornke-lineage figural memory test, Rasch Poisson Counts Model; VERIFIED, fetched and read in full via WebFetch):

1. Build an item model with one hypothesized radical (here: "visual information load," 3 levels) and several hypothesized incidentals (here: emblem-to-frame assignment, matrix-cell ordering, distractor-frame choice).
2. Generate multiple item instances per radical level, each with a different incidental combination (**N=9 items, 3 per radical level**, tested on **N=208 participants**, primarily university students).
3. Fit the full item-response model (Rasch Poisson Counts Model, RPCM — one free difficulty parameter per item) to get an empirical difficulty estimate per item.
4. Fit a **constrained/restricted model (RPCM-r)** in which item difficulty is forced to depend on the radical level only — i.e., all items sharing a radical level are forced to share one difficulty parameter, incidentals get zero weight.
5. **Decision procedure: a likelihood-ratio test between the unconstrained (RPCM) and constrained (RPCM-r) models.** If constraining to "radical alone" does not significantly worsen fit, the hypothesized incidentals are empirically incidental. If it does, at least one hypothesized incidental is actually doing work (a "leaked" radical).
6. Report the correlation between the two models' item-difficulty estimates as a secondary check (RPCM vs RPCM-r), and report each item's percent-difference from its within-family mean with a significance test as tertiary diagnostic (pinpoints *which* item/incidental is the leak, not just that one exists).

**Result reported by this source (documented failure case — directly answers the brief's ask "are there documented cases where something believed incidental turned out to be a radical"):** the radical alone explained **95.41% of variance** in item difficulty, adjusted R² = 0.939, correlation between RPCM and RPCM-r item-difficulty estimates r = 0.977 (p<.001) — strong prediction. **But the likelihood-ratio test still rejected the constrained model**, χ²(6) = 24.21, p < .001, because within-family (same radical level, different incidentals) differences were statistically significant in 2 of 3 radical levels: low-load family, one incidental combination was 6.82% easier than another (p<.05); medium-load family, one incidental combination was 12.36% harder than another (p<.001) and a third was 3.34% easier (p not stated for that pairwise). High-load family showed no significant within-family difference. The paper's own conclusion, quoted: "**True psychometrical equivalence of isomorphs cannot be assumed.**" — i.e. features initially designed as incidentals (which specific frame gets used as which distractor, cell ordering) were shown, by this exact procedure, to carry a real but small difficulty effect. This is the documented "incidental turned out to be a radical (partially)" case the brief asked for.

**Sample-size takeaway:** the one fully-worked example found uses N=208 human subjects across 9 items (3 radical levels × 3 incidental variants) — a small-N classical psychometric study by ML standards, using likelihood-ratio nested-model comparison as the statistical test, not a specific sample-size rule of thumb (none stated in any source read).

**Gap, stated honestly:** no source read gives a general **sample-size or power rule** for "how many incidental variants, how many subjects, before you can trust a null result (i.e., before failing to detect a radical-leak is itself informative rather than just underpowered)." The one worked example above found a real, small, statistically-significant leak at N=208; whether N=208 is generally sufficient to *rule out* small leaks in other domains is not addressed in any source read here. This should be flagged as an open methodological question if we adopt the procedure, not assumed solved.

**Difficulty-explained ceilings reported elsewhere (LEAD, not independently verified in full — see §8):** search-snippet summary of a different AIG item-generator study states "the item generator radical (visual load) determined the item difficulty... variance in item difficulty due to the item generator incidentals was small in comparison yet not negligible" — same qualitative pattern as PMC7298330, consistent but not independently confirmed as a separate data point (may in fact be describing the same paper via a different search snippet — treat as one finding, not two).

## 2. Candidate families

**Two AIG formalisms map fairly directly onto `T = (Theta, P_Theta, X, f, E, rho, k)`, both VERIFIED via full-text read of Gierl & Lai 2013 (NCME Module 34, fetched via Read tool on saved PDF, all 15 pages read):**

### 2a. Item model (Gierl & Lai "1-layer" / "n-layer" template) — general AIG formalism

- **`Theta`**: a concrete assignment of values to every element (slot) in the item model — e.g. for their worked surgical/hernia item, `theta` = (AGE=45, GENDER=man, PAIN=severe, LOCATION=right groin, ACUITYOFONSET=a few days ago, PHYSICALFINDINGS=tender+redness, WBC=elevated) plus the associated correct-diagnosis label. Quoted structure (Figure 2, VERIFIED): stem = `"A [AGE]-year-old [GENDER] presented with a mass [PAIN] in [LOCATION]..."`, elements = typed slots (`[AGE]` Integer 25.0–60.0 by 5.0; `[GENDER]` String 1:man/2:woman; etc.), options = the fixed answer set with constraints tying option correctness to element values.
- **`P_Theta(.|k)`**: implicit in the element value-ranges and **constraints** — e.g. quoted constraint syntax `([AGE]>40 && [GENDER]==1)` restricts which combinations are sampled; for the 1-layer surgery model, exhaustive enumeration gives exactly **16,384** combinations (`8 AGE × 2 GENDER × 4 PAIN × 4 LOCATION × 4 ACUITYOFONSET × 4 PHYSICALFINDINGS × 4 WBC`, VERIFIED from the module's own self-test answer key), i.e. `P_Theta` is uniform over the constraint-satisfying subset of a Cartesian product of typed slots. `k` is not explicit in Gierl & Lai's own formalism — it would have to be introduced as "number of elements," "number of layers (n)," or "range size per element" (see A4 triage below).
- **`X`** (query space): for a multiple-choice item, `X` is effectively fixed to "the options as generated" — the model doesn't have an open query space in the L2 sense; this AIG tradition is built for **L0-only** administration (theta stated as a scenario, examinee answers). No selection-paradigm apparatus.
- **`f`** (oracle): implicit — the correct option is fixed by the option-generation constraints tied to element values (e.g., in the n-layer example, key option "hernia repair" vs distractors, keyed by the AI/PI/S/RS scenario-to-treatment mapping in the cognitive model, Figure 5). Evaluating a candidate answer against `theta` is O(1) table lookup.
- **`E`**: `n`-layer models explicitly support **surface re-encoding as a first-class layer** — Figure 7 (VERIFIED) shows the same hernia item content re-encoded with "language" as an outer layer (English/Spanish), i.e. re-render the same theta through 4 alternate sentence-structure templates × 2 languages = **8 surface encodings of one theta**, generated automatically. This is the cleanest match found anywhere in this vein to the brief's "at least two genuinely different surface encodings" requirement — it's designed in from the start, not bolted on.
- Posterior enumerable (L3-ready)? For a 1-layer model, yes trivially — the hypothesis space is the finite Cartesian product (16,384 for the worked example) and is exhaustively enumerable by construction (IGOR, their generation tool, literally enumerates it, see below).
- `q*`: not defined — this tradition has no L1/L2/L3 apparatus; it only generates L0 items with pre-known theta baked into the stem/answer key. **If we wanted L1/L2/L3 versions, we would have to withhold the [bracketed] element values from the stem and pose them as free parameters to be identified from examples — an extension this literature does not make.**

**Generation mechanics (VERIFIED, direct quotes from Gierl & Lai 2013):**
- Two element topologies: **1-layer** (elements are flat, mutually independent/dependent/mixed/fixed per Gierl et al. 2008's four-way taxonomy) vs **n-layer** (elements nested inside other elements, "generalized form of template-based natural language generation" citing Reiter 1995) — n-layer trades tractability for combinatorial reach: their 1-layer surgery model generates 256 items, the n-layer version of the *same* underlying content generates 786,432 (`16384 × 3 QuestionPrompt × 4 TestFindings × 4 Situation`).
- **Weak theory vs strong theory** content specification (Drasgow, Luecht & Bennett 2006, cited): weak theory = start from a parent item, manipulate elements by design-guideline judgment, no explicit cognitive model, cannot predict psychometric properties in advance (field-testing/precalibration still required). Strong theory = an explicit cognitive model (their Figure 5: problem/scenario → sources of information → features → elements+constraints) drives which elements are manipulated and is claimed to support predicting item difficulty *before* administration — "by modeling the interaction between the examinee and the content, it is possible to predict and therefore control the psychometric characteristics of the generated items" (Drasgow et al. 2006, as quoted/paraphrased by Gierl & Lai). **Strong theory is rare in practice** — the module states it "has rarely been used, to-date, for AIG."
- **IGOR** (Item GeneratOR, Gierl et al. 2008) — the actual generation tool: reads an XML item model (stem/elements/options), enumerates all element-value combinations subject to constraints, outputs a test bank. This is literally the "sample theta, evaluate" backward-generation loop the brief wants for A1, already implemented and named, in a 2008 psychometrics tool.
- **Cosine similarity index (CSI)** used to quantify how distinguishable generated siblings are (word co-occurrence vectors, `cos(θ)=A·B/(‖A‖‖B‖)`); reported empirical CSI: 1-layer items had mean CSI 0.74 (SD 0.11) across 4,950 pairwise comparisons of 100 sampled items — high similarity, "homogeneous," i.e. close to clones; n-layer items had mean CSI 0.53 (SD 0.16) — more heterogeneous. **This is a direct, quantified illustration of A2/A3 risk**: 1-layer item models risk generating near-duplicate surface forms (their own pejorative term: "clones," "ghost items," "Franken-items") unless the element/layer structure is rich enough.

### 2b. Embretson's Cognitive Design System (CDS), applied to matrix reasoning — closer to a true task family

**Formalism (VERIFIED via Cambridge slide deck, 60 slides read in full; cross-checked against WebSearch snippets of Embretson 1998 *Psychometrika* and Embretson 2002 book chapter, which the deck cites but I did not fetch directly — see §8 for exact provenance split):**

- 7-step CDS process (quoted from slide, VERIFIED): (1) specify goals of measurement, (2) identify design features in the task domain, (3) develop cognitive model, (4) generate items, (5) evaluate models for generated tests, (6) bank items by cognitive complexity, (7) validate via **construct representation** (do the hypothesized processes/strategies/knowledge stores actually explain item responses — measured via difficulty-prediction fit) and **nomothetic span** (do resulting scores correlate with other measures as theoretically expected).
- Applied to **abstract/matrix reasoning items** (Embretson's Abstract Reasoning Test, ART; example figure attributed on the slide to Carpenter, Just & Shell 1990 — a 3×3 matrix of geometric figures with a systematic missing-cell, 8 answer options): cognitive model factors item difficulty into two branches (slide diagram, VERIFIED): **correspondence finding** (requires "abstraction capacity") and **goal management** (requires "working memory"); both bottom out in **"type of relationship"** and **"number of relationships"** as the actual manipulable item features, feeding "item difficulty."
- Concretely, the manipulable **radicals** for matrix items (VERIFIED, slide "Cognitive Model"): **number of rules**, **abstract correspondence** (cognitive-complexity variables) plus three **perceptual variables**: **overlay** (objects overlaid in the array), **fusion** (two objects rendered as appearing as one), **distortion** (corresponding objects rendered distorted). This is a direct, named, small parameter set that plausibly maps to a difficulty knob `k` (see below).
- **Difficulty prediction formalism named:** Rasch model (1PL) as baseline, then the **Linear Logistic Test Model (LLTM)**, with the item-difficulty parameter itself decomposed as a **linear function of the radicals**: quoted formula (VERIFIED, slide) `b_i = Σ_m η_m q_im + a`, where `q_im` = count of processing-operator `m` present in item `i` (this is literally a **Q-matrix row**, see §4), `η_m` = estimated difficulty-contribution of operator `m`, `a` = normalization constant. A worked **Q-matrix example for number-series items** was shown (Table 4, VERIFIED, 11 items × 5 cognitive operators: apprehension of succession, parallel sequences, categorisation, non-progressive coefficient patterns, progressive coefficient patterns — binary incidence matrix).
- A **Rasch-vs-LLTM scatterplot** ("5 Rule," VERIFIED) shows item-difficulty estimates from the two models tracking each other closely along the diagonal — described on-slide only as "correlational relationship," **no numeric correlation or R² value given on this slide** (unlike the PMC7298330 case, where exact numbers were stated — flagging the asymmetry: this LLTM plot is qualitative-only in the source I read).
- **Multicomponent Latent Trait Model (MLTM, Whitely 1981, cited)** — a different model from LLTM, explicitly distinguished on-slide: "LLTM estimates difficulty of complexity factors that are related to item difficulty" vs "MLTM estimates item and person parameters for component outcomes" — MLTM uses actual **subtask-level response data** (participants respond to sub-components, not just the final item), whereas LLTM only uses the final binary correct/incorrect plus a hand-specified Q-matrix of operator counts. This is a relevant methodological fork for our own Q-matrix-adjacent measurement: LLTM-style (assume the decomposition, fit weights) vs MLTM-style (get more granular data, estimate the decomposition's components directly).

**Candidate family form, matrix reasoning (Embretson-style progressive matrices):**

| Field | Value |
|---|---|
| `Theta` | a generating rule-set: which of {overlay, fusion, distortion} perceptual transformations apply, plus the number and type of abstract relations (e.g. row-wise increment, XOR-of-shapes, rotation) governing the 3×3 (or n×n) matrix |
| `k` enters via | number of rules/relations simultaneously active (LLTM's `q_im` counts), presence/absence of overlay/fusion/distortion (each empirically shown to add difficulty in Embretson's own account, per this vein's secondary source — see Hazard 1: human difficulty only) |
| `X` (query space) | in the classic (L0) administration, none — X is fixed to "which of 8 options completes the matrix." An L2 version would need to be authored (this literature does not do it) |
| oracle computes | apply the rule-set to the query cell, check whether the proposed completion matches the deterministic transformation output — O(1) |
| encoding 1 | geometric figures (shapes, line patterns) — the field's native encoding |
| encoding 2 | none demonstrated in this literature for matrix items specifically (contrast with the surgery item's language-layer trick in §2a) — **this is a real gap**: symbolically re-skinning a matrix-reasoning item (e.g. same abstract relation over tokens/numbers instead of shapes) is not shown done in any source read here, though nothing in the formalism forbids it |
| posterior enumerable (L3-ready)? | yes in principle — the rule space (which relations, how many, which perceptual ops) is small and enumerable, same structure as the number-series Q-matrix (5 binary operators → 32 possible combinations, most infeasible/uninteresting, but enumerable) |
| `q*` | not defined anywhere in this literature — no selection paradigm exists for matrix items; administration is always L0 |

**Honest translation verdict:** matrix-reasoning item models translate as a **source of a validated, human-calibrated radical set** (number of rules, overlay/fusion/distortion, relation type) and a **validated difficulty-prediction apparatus (LLTM/Q-matrix)** — genuinely the closest thing in this whole vein to a ready-made `k`. They do **not** translate as a source of L1/L2/L3 apparatus (no selection paradigm, no oracle-answers-queries structure) — that would need to be authored fresh, using the field's radical/incidental vocabulary as the difficulty-knob design guide, not imported as the reveal structure.

### 2c. Number-series items (same LLTM/Q-matrix apparatus, different content domain)

| Field | Value |
|---|---|

This is a second, independent illustration of the LLTM/Q-matrix apparatus (distinct item domain, same math), useful as corroboration that the radical→difficulty regression machinery generalizes across at least two content domains (figural matrices, numeric sequences) within Embretson's own tradition — still both human-calibrated only (Hazard 1).

## 3. Difficulty modelling and calibration

**How difficulty is predicted from radicals — three formalisms found, VERIFIED via the slide deck (with primary citations named but not independently fetched, see §8):**

1. **Rasch / 1PL model** (baseline IRT): `P(x_ij=1) = e^(θ_j−b_i) / (1+e^(θ_j−b_i))`, `b_i` = a free per-item difficulty parameter, estimated from response data, no relation to radicals yet — this is the *target* difficulty that radical-based models try to predict *in advance*, before any response data exists.
2. **Linear Logistic Test Model (LLTM)**: constrains `b_i = Σ_m η_m q_im + a` — item difficulty is forced to be a linear combination of a **Q-matrix** (`q_im`, count/presence of cognitive operator `m` in item `i`) with operator-difficulty weights `η_m` fit from data. This is the direct radical→difficulty regression the brief asks about.
3. **Multicomponent Latent Trait Model (MLTM)**: instead of regressing final-item difficulty on an assumed Q-matrix, uses actual subtask-response data to jointly estimate item and person parameters per component.

**Accuracy of prediction — exact numbers found, with source:**
- PMC7298330 (figural memory, RPCM/RPCM-r comparison, VERIFIED, body of paper): radical alone predicts item difficulty at **R² = 95.41% (adjusted R² = .939)**, correlation with actual per-item difficulty estimates **r = .977 (p<.001)** — but a likelihood-ratio test still detects a statistically real residual (χ²(6)=24.21, p<.001) from incidentals. **Read as: "excellent but not perfect" prediction, with the imperfection itself statistically confirmed, not just numerically nonzero.**
- LLTM-vs-Rasch scatterplot (Cambridge slide deck, VERIFIED, no numeric statistic stated on the slide) — qualitatively tight diagonal correlation shown for a "5 Rule" number-series condition, but **no R² or r value given in the source I read**; cannot respect the brief's numeric-accuracy requirement here beyond "the plot shows a positive correlation" — flagged as a gap, not filled in.
- No source read gives a general cross-domain accuracy figure for LLTM (e.g., "LLTM explains X% of variance in item difficulty across N studies") — only the two single-study data points above.

**Hazard 1 applies directly:** every one of these difficulty-prediction results is calibrated against **human response data** (N=208 in the one fully-quantified case). None of it says anything about whether the same radicals would predict difficulty for a sequence model. Reported here strictly as an externally-attested apparatus (the LLTM regression machinery, the Q-matrix representation) and an externally-attested *human* accuracy ceiling, per the brief's instruction — not as a difficulty measure that transfers.

## 4. Q-matrix estimation and failure modes

**Treated strictly as prior art for our own all-pairs-transfer measurement, per the brief — not as a source of task content.**

### 4a. Formalism (VERIFIED — Zhang, DeCarlo & Ying, "Non-identifiability, equivalence classes, and attribute-specific classification in Q-matrix based Cognitive Diagnosis Models," arXiv:1303.0426, fetched and read in full through §9.2, body text; and Liu, Xu & Ying, "Data-driven Learning of Q-matrix," fetched and read through §2, formalism/methodology)

- **Q-matrix**: `Q = (q_jk)`, `J` items × `K` attributes, binary, `q_jk=1` iff item `j` requires attribute `k`. This is precisely the object the brief identifies as "the same object" as our own capability-decomposition target — a mapping from tasks (items) to the capabilities (attributes/skills) they require.
- **DINA model** (Deterministic Input, Noisy "AND" gate — the standard, most-cited CDM, quoted formula, VERIFIED): ideal response `ξ_j(Q,α) = 1(α_k ≥ q_jk for all k)` — i.e. conjunctive: a respondent needs *every* attribute the item's Q-matrix row calls for; extra attributes don't compensate for a missing one. Actual response is Bernoulli with slipping parameter `s_j` (P(wrong | should be right)) and guessing parameter `g_j` (P(right | should be wrong)).
- **DINO model** (Deterministic Input, Noisy "OR" gate) — the disjunctive dual: `ξ_j(Q,α) = 1(α_k=1 for some k with q_jk=1)`, i.e. possessing *any one* of the required attributes suffices. The paper shows DINO is exactly DINA on the bit-flipped response/attribute space — "this dualism implies that all the results of this paper apply to the DINO model" (VERIFIED quote).
- **Estimation approaches**, named across sources: (1) expert-specified Q-matrix, fixed, then fit item/person parameters (the classical approach, "typically performed by content experts" per search-snippet synthesis of the broader literature — LEAD); (2) **statistical refinement/validation** of an expert-specified starting matrix; (3) fully **data-driven estimation** from response data alone (Liu, Xu & Ying's contribution, VERIFIED) — builds a "**T-matrix**," a deterministic linear transform of any candidate `Q'` into the space of predicted joint-response probabilities, then picks the `Q'` whose predicted probabilities best match the empirical response distribution (equation `β → T(Q)p` as `N→∞`, VERIFIED quote/derivation read in full); explicitly generalizes beyond DINA to DINO, NIDA, NIDO.

### 4b. Identifiability — the central, formally proven failure mode (VERIFIED, full worked example read)

**Core result:** an *incomplete* Q-matrix (one lacking, for every attribute `k`, at least one item that requires `k` and *only* `k` — "Proposition 2," VERIFIED) makes some attribute-profile pairs **statistically indistinguishable no matter how much data you collect.** Two profiles `α¹≠α²` are "separable" (Definition 1, VERIFIED) only if they produce different *ideal response vectors*; if they don't, "any differences in their posteriors [are] simply artifacts of the prior" (direct quote). Formal partition machinery: "equivalence classes" `[α]` group all profiles that are unseparable given a Q-matrix; a Q-matrix is "complete" (Definition 3) iff it induces the everywhere-fully-separated partition (needs one item devoted solely to each attribute — Proposition 2, `O(JK·2^K)` algorithm given in Table 1 for computing the partition for any Q).

**Worked numeric example (VERIFIED, direct quote/derivation), directly usable as an illustration of the failure mode:**
```
Q3 = [[1,0,0],
      [1,1,0],
      [0,1,1]]
```
gives 5 equivalence classes over the 8 possible 3-attribute profiles: `[000]={000,010,001}` (3 profiles collapsed into one), `[011]`, `[100]`, `[110]`, `[111]` (singletons). Attribute 2 is only identifiable for part of the population; profiles `(0,1,0)` and `(0,0,0)` remain "statistically identical" ("still indistinguishable") even with this richer 3-item, 3-attribute design — **adding a third attribute to a Q-matrix that already has the problem does not automatically fix it.**

**Simulation, exact numbers (VERIFIED, Table 9, §9.1):** `N=5000` simulated respondents, `J=6` items, `K=3` attributes, incomplete/simulated Q-matrix (Table 5). Marginal misclassification rate for attribute 3 (the non-identifiable one): **DINA and HO-DINA range 0.19–0.44 across 10 random-start EM runs — "the misclassification rate for Attribute 3 may reach over 40% in both models"** (direct quote). The paper's own fix (NIAD-DINA: classify only when posterior confidence clears 0.5 after accounting for the equivalence-class structure) reduces the *classified* subset's error to 0.04–0.07 but **leaves 32–56% of respondents formally unclassified** (`*`) rather than wrong — i.e., the fix trades misclassification for admitted non-identification, it does not make the information appear.

**Real-data case, exact numbers (VERIFIED, §9.2, Tatsuoka 1990's fraction-subtraction dataset — 20 items, 8 attributes, Q-matrix from de la Torre & Douglas 2004, cited within this paper, not independently fetched):** with 8 attributes there are 256 possible profiles; the actual Q-matrix used in this widely-analyzed, real (not simulated) dataset collapses them into only **58 equivalence classes, of which just 32 are singletons** — the other 26 classes contain multiple indistinguishable profiles, one as large as **64 members** (Table 15, class `[00000000]`, size 64). Marginal identifiability rate for Attribute 3: **ζ₃ = 0.48** — "bringing into question the ability of this assessment to measure mastery of Attribute 3" (direct quote). Attribute 6: ζ₆ = 0.64.

**Documented interpretive absurdity, real dataset (VERIFIED, direct quote, citing DeCarlo 2011 within this paper):** in the same fraction-subtraction data, the ind-DINA model variant assigns *high* posterior mastery probability to several skills for students who answered **every item wrong** — "students with a score of zero cannot subtract numerators, but can do everything else, from finding a common denominator to borrowing to reducing to simplest form" (direct quote, exact numbers: ind-DINA posterior P(attribute=1 | all-zero responses) = 0.74 for attribute 1, 0.86 for attribute 2, 0.96 for attribute 3, 0.86 for attribute 4, 0.75 for attribute 5, 0.98 for attribute 6, 0.00 for attribute 7, 0.94 for attribute 8 — Table 14, VERIFIED). **This is exactly the "prior negative result" the brief asked to prioritize**: a real, published, widely-cited diagnostic dataset producing a model-based skill decomposition that is diagnosable as nonsense by inspection, traced by the paper's own analysis to (a) an incomplete/poorly-designed Q-matrix (Attribute 3 appears in only one item, always in conjunction with three other attributes; Attribute 7 is required by all but one item, making it impossible to learn anything about *other* attributes from anyone who fails on Attribute 7) and (b) using an under-restrictive model variant (ind-DINA) not robust to that incompleteness.

**Root cause, stated generally by the paper:** non-identifiability in the DINA model specifically afflicts **attributes that appear only in conjunction with other attributes**, never alone — "this is due to an issue with attribute identifiability, which has long been known (Tatsuoka 1991; DiBello, Stout & Roussos 1995; DeCarlo 2011) but tends to be ignored in practice" (direct quote). Also documented: "recovering information about the latent variables from a '0' response may be difficult" — a correct response to a conjunctive item is informative (implies mastery of all required attributes), but a wrong response is not (any one missing attribute among several would produce the same wrong response) — a structural asymmetry, not a data or sample-size problem.

### 4c. Misspecification (Q-matrix wrong, as opposed to merely incomplete) — LEAD, not independently fetched

Search-snippet synthesis of Rupp & Templin (2008, *Educational and Psychological Measurement* 68(1):78–96 — title and journal citation found, **full text not fetched, exact classification-accuracy percentages not independently verified**) and related G-DINA misspecification simulation studies: Q-matrix misspecification "influenced classification accuracy more ominously than model misuse" (i.e., getting the Q-matrix wrong hurts more than picking the wrong CDM given a correct Q-matrix); **underfitting** (an attribute a real item needs is omitted from its Q-matrix row) inflates estimated slipping parameters; **overfitting** (a spurious attribute added to an item's row) inflates estimated guessing parameters. This is a directionally-clear, qualitatively multiply-corroborated finding across the search results but **no source read here gives an exact number** ("accuracy dropped from X% to Y%") that meets this report's evidentiary bar — flagged as LEAD, not stated as a number.

### 4d. Rule Space Method (Tatsuoka) — LEAD only

Tatsuoka's Rule Space Method (RSM), the historical precursor to modern CDMs, is described in search-snippet synthesis (not fetched) as converting item response patterns into attribute-mastery probabilities via a Q-matrix, and was reportedly used operationally to generate cognitively-diagnostic score reports for the PSAT/SAT testing programs. One directly relevant title found but **not fetched**: Im & Corter (2011), "Statistical Consequences of Attribute Misspecification in the Rule Space Method," *Educational and Psychological Measurement* — title alone confirms rule-space misspecification is a studied failure mode paralleling the DINA-model identifiability results above, but no numbers from it are reported here.

### 4e. Synthesis — what this means for our own transfer-block measurement

Three transferable warnings, all traced to VERIFIED sources above, stated as inferences (labeled as such) rather than the source's own claims:

1. **Incompleteness is silent.** A Q-matrix (or, for us, an all-pairs-transfer matrix) can look reasonable and still make some capability distinctions formally unrecoverable from any amount of data — the failure is structural (which tasks exist / which comparisons are available), not statistical power. *Inference from §4b*: before trusting a recovered block structure, we should check whether our own family-pair matrix has the equivalent of "one family devoted solely to each hypothesized capability" — i.e., whether every capability we hypothesize has at least one family that isolates it from all others, analogous to Proposition 2's completeness condition.
2. **Conjunctive (AND-gate) structure hides attributes that never appear alone.** *Inference*: if in our measurement a capability only ever co-occurs with others (no family requires it in isolation), our recovered decomposition will be unable to tell "requires that capability" from "requires whatever it always travels with" — mirroring DINA's attribute-3 problem exactly.
3. **A decomposition that looks confident can still be nonsense** — the fraction-subtraction "zero-score-but-high-mastery" case is a documented example of exactly the interpretive trap the brief warns about (Hazard 2, "the recovered skills are real or artifacts"). *Inference*: sanity-check any recovered block structure against degenerate cases (e.g., what does the recovered decomposition say about a model that fails everything, or passes everything) before trusting it, the same way DeCarlo's critique caught the fraction-subtraction absurdity by inspection.

## 5. A2 evidence — culture-fair testing

**What was tried:** non-verbal / figural test batteries explicitly designed to minimize dependence on language, schooling content, and specific cultural knowledge — the two flagship examples found are the **Cattell Culture Fair Intelligence Test (CFIT)** and **Raven's Progressive Matrices (RPM)**, both matrix-completion/figural-reasoning formats (VERIFIED, Wikipedia, fetched directly): CFIT "consists of three scales with non-verbal visual puzzles" — Scale I: "mazes, copying symbols, identifying similar drawings"; Scales II/III: "completing a sequence of drawings, a classification subtest..., a matrix subtest that involves completing a matrix of patterns, and a conditions subtest." This is the same figural-matrix format as Embretson's ART (§2b) — the culture-fair tradition and the AIG/CDS tradition converge on the identical item format, independently.

**How leakage was detected — the actual apparatus, extractable from the above (this is the operationally useful part):** every documented detection method is a **differential item functioning (DIF) style comparison**: hold total-score (or IRT-estimated ability) constant, then check whether *per-item* pass rate still differs by group. Concretely, four distinct statistical machineries were named as having been applied to exactly this test: (1) Scheuneman's chi-square (compare observed-vs-expected per-item correct rates within ability strata across groups), (2) Rudner & Convey TID-45 (transform item difficulty estimates and compare across groups), (3) Rasch-model item-fit / DIF (compare item-difficulty-parameter estimates by group, flag items whose group-specific fit diverges), (4) Cochran's test (a stratified chi-square test for consistency of an association — here, group membership vs. item correctness — across strata of the matching variable). **The methodological lesson for A2, stated as inference:** "knowledge-free" cannot be verified by inspection of item content alone (these items were deliberately designed to look content-free and still leaked); it requires an empirical differential-performance check across groups expected to differ only in the confound you're trying to exclude — for us, that would mean checking whether a sequence model's performance on a nominally "knowledge-free" family is invariant to *symbol-alphabet identity* in fact (per A2's own stated criterion), not just invariant by design intent.

**What specifically leaked — mechanism, as best attested (mostly LEAD, stated with that caveat):** not specific factual content (the whole point of geometric/figural items is to avoid namable facts), but **format familiarity and reasoning-style exposure** — familiarity with multiple-choice conventions, exposure to "abstract, analytical" visual reasoning as a schooled skill, prior test-taking experience, and (per the Flynn-effect circumstantial evidence) something that improved population-wide over the 20th century in a way tracking modernization/schooling more than tracking any single fact. **No source read here identifies a specific concrete item or a specific piece of leaked content** (e.g., "item 23 secretly requires knowing X") — the detection methods operate at the statistical/aggregate level (this item's difficulty differs by group) without necessarily explaining *why* in item-content terms. This is a real gap in what was found, stated honestly rather than papered over.

## 7. Primitives

**Reused (with folded source terms):**

| Existing primitive | Source terms folded in |
|---|---|
| `abstraction-naming` | Matrix-reasoning rule identification (Embretson's "correspondence finding," Carpenter/Just/Shell-style matrix solving): given two or more complete rows/columns exhibiting the same abstract transformation, factor out the shared generative rule and apply it to the incomplete row — this is anti-unification over the given complete instances, exactly the primitive's definition. Number-series operator identification (§2c: apprehension of succession, parallel sequences, categorisation) is the same operation over a 1-D sequence instead of a 2-D grid |
| `structure-walk-query` | Traversing a matrix row-by-row/column-by-column (or a number sequence term-by-term) to locate where the pattern applies and where it's violated (the missing cell) |
| `constraint-propagation` | Embretson's "number of relationships" / LLTM's `q_im` count directly: when multiple rules act simultaneously on the same grid (row rule AND column rule AND a perceptual op like overlay), narrowing the space of valid completions requires combining constraints from each active rule — same operation this primitive already covers in other veins |

**Justification for not proposing a new "analogical mapping / relational alignment" primitive, as the brief invited us to consider:** matrix-reasoning's "correspondence finding" (Embretson's own term, §2b) sounds distinct at first — it names *which features in panel A correspond to which features in panel B* before the transformation between them can be described. On inspection this decomposes into exactly the two primitives above: (1) `abstraction-naming` to identify the transformation itself (what rule, applied to what role-slots, explains the given complete rows), and (2) `structure-walk-query`/`constraint-propagation` to apply and check it against the partially-specified target. **No residue was found that these two don't already cover** — "correspondence finding" is not a separate cognitive operation in the formalism actually read (Q-matrix / LLTM), it's Embretson's cognitive-psychology *label* for the same rule-abstraction-then-application pattern, not a distinct computational step. This is a considered rejection, not a default: the fold was tested against the one worked mechanism this vein actually specifies (LLTM's `q_im` operator-count structure), and that mechanism has no third term beyond "which operators are present" (→ abstraction-naming's target) and "how many/which combination" (→ constraint-propagation's domain).

**Zero new primitives proposed this vein** — this vein's contribution to the running tally is +0. This vein's content is overwhelmingly about *generation methodology and measurement apparatus* (item models, radicals/incidentals, Q-matrices, difficulty calibration, bias detection) rather than *new task-solving operations* — the one genuinely new task-content candidate found (matrix reasoning) folds cleanly into existing primitives, and the Q-matrix material is explicitly scoped by the brief as prior art for our own measurement, not a source of primitives at all.

## 9. Source's taxonomy (quarantined — not adopted, recorded for later scoring)

- **Embretson's Cognitive Design System ontology**: item difficulty is explained by a specific two-branch cognitive-process taxonomy — "correspondence finding" (requiring "abstraction capacity") and "goal management" (requiring "working memory") — with "type of relationship" and "number of relationships" as the measurable substrate. This is Embretson's own theory of *what matrix-reasoning items measure psychologically* (a working-memory/abstraction-capacity dual-factor account). Quarantined per Hazard 2 — not adopted as our capability decomposition; if our own empirical measurement later produces a block structure over matrix-reasoning-derived families, it can be scored against this two-factor prediction, but not assumed to match it.
- **Rasch/IRT's own construct**: a single scalar latent trait `θ` ("ability") sufficient to explain all item responses via a monotone response function. This is IRT's foundational unidimensionality assumption — quarantined; our measurement is explicitly meant to recover a *multi-block* capability structure, and importing unidimensional IRT's own ontology would beg the question.
- **CDM/Q-matrix field's own ontology**: a fixed, expert-specified, discrete set of named "attributes" or "skills" per content domain (e.g., the 8 named fraction-subtraction skills: convert whole number to fraction, separate whole number from fraction, simplify before subtracting, find common denominator, borrow from whole number, column-borrow, subtract numerators, reduce to simplest form) is *the* correct decomposition, existing prior to and independent of any model fit to it. Quarantined explicitly and heavily, per the brief's Hazard 2 instruction — this is precisely the "ready-made skill taxonomy" the brief warns against importing, made especially salient here because the very Q-matrix machinery we're borrowing as *measurement apparatus* (§4) comes bundled with this ontological assumption in its home field. We take the apparatus (T-matrix estimation, identifiability/equivalence-class analysis, misspecification failure modes) and explicitly leave the assumption that "attributes" named by content experts in advance are the real, correct, or complete decomposition.
- **Culture-fair testing's own construct**: "fluid intelligence" (Cattell's `g_f`) as a real, unitary, content-independent cognitive capacity that a sufficiently well-designed figural test could isolate. Quarantined — the field's own bias-detection results (§5) are evidence *against* full success at this, which is exactly why they're useful to us, but the underlying construct-validity claim ("this measures a real, unitary thing called fluid intelligence") is not adopted.
